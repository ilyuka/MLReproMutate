# MLReproMutate Benchmark

This directory contains the protocol and metadata used to evaluate
MLReproMutate on real open-source machine-learning research repositories.

The benchmark corpus has not yet been finalized.

Repository selection criteria, exclusions, commit identifiers, experiment
configuration, and results will be documented before the full empirical study
is conducted.

The benchmark will avoid selecting repositories based on whether they produce
favorable MLReproMutate results.
