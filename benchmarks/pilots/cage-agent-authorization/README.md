## Observations

`setup.sh` reported a SHA-256 mismatch for
`bridge_benchmark/experiments/mcp_substrate/registry_adjudicate.py`,
while its final summary still reported zero failures.

This was recorded as an upstream artifact observation and was not modified.

The first MLReproMutate run was stopped after observing that the current
evaluation architecture repeats the successful baseline for every mutation
candidate. With a 172.40-second baseline, this creates substantial redundant
execution cost.

This observation motivates baseline reuse in the orchestration layer.

### Validation side effects

Running the upstream validation command (`python -m pytest -q`) directly in
the repository created untracked output directories:

- `bridge_benchmark/cert/out/_test_ais/`
- `bridge_benchmark/cert/out/_test_mga/`
- `bridge_benchmark/cert/out/_test_rd/`

These outputs were generated by the upstream validation workflow and were
removed before mutation evaluation.

This observation reinforces the use of isolated temporary workspaces for both
baseline and mutated validation runs.
